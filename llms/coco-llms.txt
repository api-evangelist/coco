# Coco Robotics

> Coco Robotics is a Santa Monica, California urban robotics company operating a fleet of
> zero-emission, remotely-supervised sidewalk delivery robots ("Cocobots") for last-mile food,
> grocery and retail delivery in Los Angeles, Chicago, Miami, Jersey City and Finland.

## API surface

Coco Robotics publishes **no public API**. As of 2026-08-09 there is no developer portal, no API
reference, no OpenAPI/AsyncAPI/GraphQL contract, no SDK, no webhook catalog, no MCP server and no
A2A agent card on any Coco host. Merchants do not integrate with Coco directly — Coco is consumed
as a delivery service provider through third-party ordering platforms.

- Ordering platforms that dispatch Coco: Uber Eats, DoorDash, Wolt, Olo Dispatch
- Merchant onboarding is a sales conversation, not a developer signup: https://www.cocodelivery.com/contact-delivery
